# Integrated Web App Dashboard

A React data dashboard built with Vite and TypeScript integrated with an ASP.NET Core API that processes data coming from the external API: https://restcountries.com/ .

## Live Preview

- Dashboard: https://credit-xpert-code-exercise.vercel.app

## Prerequisites

- Node.js (v18 or higher)
- NPM

## Local Setup & Execution

Run the CountriesApi from CountriesApi directory:

```bash
dotnet restore
dotnet run
```

Run the Client from client directory:

```bash
npm install
npm run dev
```
